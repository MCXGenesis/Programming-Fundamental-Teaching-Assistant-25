# **Problem: MOLE**

SWEETHEART’S QUEST FOR HEARTS contest has reached its special episode! SWEETHEART is now looking for MOLE of her life. MOLES all over the HEADSPACE gather to try their luck of love. However, there are some FAKE MOLES in the queue. SWEETHEART’s guard realizes this and allows all MOLES (either real or fake) to enter one by one, but as soon as the number of REAL MOLES exceeds twice the number of FAKE MOLES, the guard closes the gate. 

I wonder if you can count how many MOLES in the queue are allowed to enter the contest.
    
**Special test case:**
If the queue only consists of FAKE MOLES, do not accept all of them.

The queue can be represented as Q consisting of N strings separated by space, either ‘MOLE’ as a real one or ‘imitation words of MOLE’ as a fake one.

**Input Format:**

- The first line of input will contain a single integer T, denoting the number of test cases.
- Each test cases consists of two inputs:
    - First line contains integer N, denoting the length of Q
    - Next line is Q containing N string S, denoting MOLES in the queue
